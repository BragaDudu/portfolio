## 📋 Sobre

Portfólio profissional desenvolvido do zero, sem templates ou frameworks, demonstrando domínio dos fundamentos da web.

## ✨ Funcionalidades

- ⚡ Tema Dark/Light com persistência (LocalStorage)
- 📱 100% Responsivo (mobile, tablet, desktop)
- 🎯 Seção de projetos dinâmica
- 🔗 Links para redes sociais
- 🎨 Interface moderna e profissional

## 🚀 Tecnologias

- **HTML5** - Estrutura semântica
- **CSS3** - Flexbox, Grid, Animations
- **JavaScript (ES6+)** - DOM, LocalStorage, Arrow Functions

## 🎨 Paleta de Cores

### Tema Light
- **Background:** `rgb(250, 250, 251)`
- **Primary:** `rgb(0, 55, 255)` (Azul)
- **Accent:** `rgb(14, 165, 233)` (Azul Claro)

### Tema Dark
- **Background:** `rgb(24, 24, 27)`
- **Primary:** `rgb(239, 122, 68)` (Laranja)
- **Accent:** `rgb(220, 38, 38)` (Vermelho)

## 💻 Como Rodar

1. Clone o repositório
```bash
git clone https://github.com/BragaDudu/portfolio.git
```

2. Abra o arquivo `index.html` no navegador

## 📂 Estrutura
```
portfolio/
├── index.html     # Estrutura da página
├── styles.css     # Estilos e tema
├── script.js      # Lógica e projetos
└── foto
```
